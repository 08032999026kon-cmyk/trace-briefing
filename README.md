# TRACE v23 — 机上の帳票から証拠を探す税務調査ストーリー

机の上に置かれた帳票の束から見る資料を選び、ページをめくって証拠を社長に示すWebゲーム。3つの架空事件・計60ページを収録。音声はありません。人物・名前・台詞は、分かりやすい悪役漫画の演出にそろえています。

体験URL：https://trace-tax-experience.aaa305309.chatgpt.site

本人限定。同じChatGPTアカウントで開いてください。ローカルではフォルダーの **index.html** を開くだけで動きます。ビルド、インストール、APIキー、有料サービス、実行時LLMは不要です。

## エピソード

| 事件 | 題材 | 帳票 |
|---|---|---|
| 01 黒金社長の売上隠し | 取消処理で帳簿から外れた売上60万円 | 10束・32ページ |
| 02 銭守社長の外注費偽装 | 請求はあるが未実施の外注業務90万円 | 7束・14ページ |
| 03 豪田社長のニセ出張 | 報告書と実際の旅行が食い違う精算28万円 | 7束・14ページ |

各約10分。事件ごとにプロローグと3つの主張の検証があります。プレイヤーは、法人税の税務調査で各社を訪問している税務署の調査官です。

## 机上の資料を調べる

1. 起動時は必ず事件選択の入口を表示。新規の事件を選び、3場面で「自分の役割と現在地」「ここまでの手がかり」「最初に確かめること」を確認する。前へ・次へ・スキップに対応。
2. 社長の説明を聞いたら、机の画面へ。**すべての帳票が開始時から机にあります。**
3. 見たい帳票の束を押して開く。紙束には原帳票のプレビューと中立的な資料名・ページ数を表示します。
4. 前後ボタン、スマホの左右スワイプ、PCの左右矢印でページをめくる。
5. 帳票上部の大きな「このページを証拠に選ぶ」カードを押す。スマホでは、読んだ位置のまま画面下の同名ボタンからも選べます。選べるのは1ページです。別のページを選ぶと入れ替わり、同じページをもう一度押すと外せます。選択内容を確認して社長に提示します。
6. 画面上部の判定と社長の反応を読む。正解なら「帳票でおさらいする」で決め手を確認し、その画面から次の説明へ進む。正解でない場合は、理由を読んで資料を選び直す。

机の配置・候補・順序は進行で変わりません。新着・NEW・推薦表示や、途中の資料追加はありません。操作履歴やメールの保管記録も初めから同じ机にあります。束の装飾が変わるのは利用者がページを選択した場合だけです。

新しい調査では、各場面で確かめる事実に合う帳票を1ページ提示します。一度確認した帳票を次の場面で重ねて示しても、話は進みません。メールを早く見つけた場合は指示の手がかりとして扱い、納品・代金・作業や旅行の実態は別の記録で裏付けます。時間制限・減点はありません。

## 1ページずつ、別の事実を確かめる

新しい調査の証拠は1回1ページ。次の場面では、すでに使った同じ帳票ファイルを再提示しても進みません。別ページに替えても、同じファイルでの確認の繰返しにはしません。

| 事件 | 1つ目の確認 | 2つ目の確認 | 最後の確認 |
|---|---|---|---|
| 売上 | 商品の引渡しの記録 | 別の帳票で代金の受領 | メールに残る取消指示 |
| 外注費 | 会社側の受領・検収記録 | 外注先の実施状況の回答 | メールに残る計上指示 |
| 旅費 | 打合せの実施状況の記録 | 手配先の参加者・内容の回答 | メールに残る精算指示 |

メールの記述を無視したり誤りと決めたりせず、実態の裏付けと指示者の確認を分けます。売上の取引先回答を最初に使った場合は、次に領収書控えで代金を確認でき、行き止まりにはなりません。

## いま何を確かめるかを、常に表示

机と帳票の上部には、社長の主張と **赤字の問い** を常に表示します。主張は折り畳まず、クリック不要。PCは横並び、スマホは同じ枠の中で縦に並べ、問いを赤字で示します。

たとえば「商品は渡していない」には **「商品を受け取った事実は、どの書類で確かめられるだろう？」** と表示。全3事件・9場面で問いが切り替わります。正解の資料名を最初から示さず、確かめる事実を明確にします。

ヘッダーは遊び方とメニューに整理。証拠手帳・最初からやり直す・動き設定・出典はメニューにまとめます。詳しいヒントは遊び方の中で任意に読めます。机の重複ボタン・未選択時の下部帯、帳票の重複する拡大ボタン、結果画面のメニューと重複する操作を減らしました。全帳票の固定配置は維持しています。

説明のための小見出しや同じ意味の注記を整理し、問いを直接読める表示にしました。机の重複見出し・開く案内、提示ボタンと重なる注記、答え合わせの重複する導入文を削減。取引番号・対象・正誤の理由・選択ルールは維持しています。保存成功の常設メッセージは外し、保存できない場合の警告は引き続き表示します。

## 机への戻りと調査対象の固定表示

調査を始めた後は、画面上部に **机に戻る** と、会社・社長・調べている取引を固定表示します。取引先・内容・取引番号・金額・期間をまとめ、別取引の帳票を開いても元の対象を表示し続けます。PC・スマホとも、スクロール中も確認できます。

原寸表示・証拠手帳・おさらい・やり直し確認にも同じ欄を設けています。通常の調査では選択・閲覧ページを保って資料の机へ戻ります。正解の反応・おさらい中や調査完了後は、進行を変えない資料の見返しを開きます。見返しでは証拠を選んだり提示したりせず、元の反応・結果へ戻れます。入口とプロローグでは固定欄を出しません。

## 閲覧・操作

標準は画面幅に合わせた実務帳票。要約表示はありません。「拡大して読む」で現在の1ページを原寸表示し、幅合わせへ戻せます。縦スクロール・ピンチ・文字選択・拡大中の横パンはめくり判定から除外します。

ページの選択は、帳票上部のカード全体で操作できるチェック欄1つ。選択後は「このページを証拠に選択中」と表示し、再度押すと外せます。選択だけでは提示されません。

PCは帳票横に選択トレイ、スマホは画面下に操作帯を表示。未選択なら「このページを証拠に選ぶ」、選択中のページなら「1ページを社長に示す」、別のページを閲覧中なら「このページに入れ替える」と表示します。「選択を確認」には選んだ帳票名を表示し、確認画面でページを見返してから、そのまま提示できます。選択と提示は別操作です。

遊び方・証拠手帳は、長くスクロールしても閉じる操作を画面内に残す構成に変更。操作部分の文字・余白・押す範囲を調整しています。誤提示後は元ページへ直接戻れます。机・帳票・事件一覧のスクロール位置も保持します。

- **メニュー → 証拠手帳**：確認した矛盾、提示したページ、会話を読む。
- **遊び方**：現在の操作、任意の詳しいヒント、役割・調査の状況、プロローグ全文を読む。
- **メニュー → 最初からやり直す**：確認後に **3つの事件すべて** を初期化し、事件一覧へ戻る。キャンセルなら変更なし。
- **メニュー → アニメ／この体験・出典**：アニメの再生・停止、出典と前提。端末の動き軽減設定と明示した設定を尊重。

## プロローグで調査の状況を確認

3場面すべてに役割・訪問先・対象取引を表示。本文は「税務署の調査官として会社へ訪問中 → ここまでに見つけた手がかり → 社長の説明と、最初に確かめること」の順です。

- 売上：出荷記録があるのに売上帳に計上が見当たらない。まず実際の引渡しを確認。
- 外注費：年度末の90万円の計上時に、添付資料が請求書だけ。まず成果物の受領・内容確認を調べる。
- 旅費：打合せ出張の精算に、リゾート宿泊や体験チケット。まず打合せの実施を確認。

手がかりだけで不正と決めず、受領・未着手・中止・家族旅行等の結論は調査前に明かしません。スキップした場合も、社長の説明画面の「調査の状況を確認」と「遊び方」で読み返せます。

## 社長の反応を見てから、おさらい

的確な資料を提示すると、**まず社長の表情と返答**を表示します。「帳票でおさらいする」を押すと、実際に提示した原帳票で決め手を確認できます。自動でおさらい画面を重ねません。

- まず帳票1ページ全体を画面内に収め、見る場所を番号付きの枠で表示。
- アニメONでは約1.4秒後、同じ紙面を約0.9秒かけて注目箇所へ拡大。受領日・金額・未着手・中止・指示文などを読む。
- 「全体を見る」で全体表示を維持。「ポイントへ拡大」ですぐ拡大できる。アニメOFFでは全体表示から手動で切り替える。
- 番号付きの枠と、何を確認する箇所かの短い解説を表示。
- 番号のボタンで見るポイントを切り替え、帳票全体でも位置を確認。
- 新しい調査は、実際に提示した1ページだけをおさらい。旧版の複数提示記録では、当時提示した的確な資料の切替も維持。
- おさらい下部の「社長の次の説明へ」で次へ進む。最後の幕では「調査結果を見る」。
- 「閉じる」やEscapeでは社長の反応へ戻り、幕は進まない。
- 調査結果・証拠手帳からの再読は確認専用。進行を変えず元の画面へ戻る。

注釈は指摘が的確だった後だけ表示します。通常の机・閲覧帳票を改変せず、最初から答えを色付けしません。新ルールの11パターンと、旧記録を読み返すための17パターンに対応しています。

3人は **黒金 欲蔵／銭守 勘蔵／豪田 遊作**。絵・導入・名前・台詞とメール等の名義を統一。取引番号・金額・日付・原帳票は維持し、新ルールでは場面ごとの判定を独立した裏付けに整理しています。旧保存の役名は表示時だけ新しい名へ読み替え、保存済みの会話自体は書き換えません。


## 正解・やり直し・調査クリアを明示

証拠提示後は、**正解／不正解（別取引・別期間）／証拠不足／確認済み**を、大きな見出しと記号で表示します。次へ進めるか、選び直しが必要かも明記。社長の返答の下で、正解の理由・進めない理由を説明します。手がかりとして有用なメールは、虚偽や別取引とは区別して「別の帳票で裏付けが必要」と表示します。

3つの確認に正解し、最後のおさらいから結果へ進むと、トロフィーと **CASE CLEAR／調査クリア！／3つの正解済み項目**を表示。誤提示があっても、必要な証拠をそろえればクリアできます。誤提示の回数で減点したり、全問を一度で正解したと扱ったりしません。

結果の解説は「事件の答え合わせ」として結論を先に表示。売上事件は東雲の出荷前取消と若葉の納品済み取引を比較し、指示メール→取消処理→本人の返答を時系列で示します。外注費・旅費も、書類の説明と実際の記録を比較。金額の意味と対象外の法律判断は、別の補足欄にまとめます。原帳票での振り返りも引き続き利用できます。

## 結果で、実際の帳票を比較

「あなたがつないだ証拠」は、3つの確認をPCでは横並び、スマホでは幅に収まる縦並びで表示。実際に提示した決め手の帳票をそのまま掲載し、赤枠・番号と同じ番号の解説で注目箇所を示します。別解で進めた場合も、そのとき提示した帳票を表示します。

「赤枠を拡大して確認」は、そのカードの帳票のおさらいを開きます。原票表示と、提示した全ページの一覧も利用可能。旧版の複数提示記録でも余分な資料を決め手として強調せず、未提示の正解資料を代わりに表示しません。保存・進行を変えず読み返せます。

## 説明会のグループ体験（v24 追加）

1グループ数名で、**全員が自分のスマホで帳票を読み、社長に示すのは代表だけ**にする使い方です。サーバーは不要ですが、参加者のスマホから開ける公開URL（https）にフォルダーごと置く必要があります。

| ページ | 使う人 | できること |
|---|---|---|
| index.html | 代表（1グループ1台） | 従来どおり全操作。証拠の選択・社長への提示ができるのはこの画面だけ |
| member.html?case=e1 | メンバー全員 | 机の全帳票を自由に閲覧・拡大・スワイプでめくる。主張1〜3の切替と赤字の問いの表示。選択・提示のボタンはない |
| group.html | 運営スタッフ | 公開URLと事件を入れると、代表用・メンバー用のQRを並べた印刷用シートを作る |
| host.html | 司会（投影PC） | 説明会の投影用進行画面11枚（ルール・QR・調査タイマー・答え合わせ・仕事紹介）。「設定」で会社名・開始時刻・事件・文面を保存 |
| staff.html | フロアスタッフ | 主張ごとの正解帳票・ページ番号・2段階ヒントを、物語データから生成して印刷。公開用フォルダーには入れない |

- メンバー画面は代表の進行と同期しません。主張の番号は代表の画面に合わせて各自が切り替えます（画面同期は今後の段階2）。
- メンバー画面は代表側の保存（trace-cases-v8）を読み書きせず、閲覧位置だけを `trace-member-v1` に保存します。
- 代表かどうかは「どのURLで開いたか」で分ける簡易な仕組みです。URLを書き換えれば誰でも代表画面を開けます。
- index.html と既存スクリプトは変更していません。QR生成に vendor/qrcode.js（qrcode-generator 1.4.4、MIT License、Kazuhiko Arase）を同梱しています。
- 検証：`node tests/member-view.cjs`。ChromiumのiPhone幅エミュレーションで表示・拡大・保存を確認済み。スマホ実機は未検証です。

## 開いたときは、入口から

保存があっても、ページを開いた直後に途中の調査へ移りません。必ず事件一覧の先頭を表示します。

保存済みの進行がある場合は「最初から始める」を目立つ位置に表示。確認後に全3話を初期化し、新しい調査を始められます。「続きから」や「調査結果を見る」を自分で押したときだけ、該当する記録を開きます。保存がない場合は事件を選ぶだけでプロローグの最初へ進みます。開くだけでは保存の書換え・削除は行いません。

ブラウザーの戻る操作でページの状態が復元された場合も、開いていた帳票・手帳等の画面を閉じ、入口へ戻します。プレイ中にほかのタブへ切り替えただけでは中断しません。

## 保存とやり直し

新規調査は `rulesVersion:2`。既存の保存は `rulesVersion:1` として、過去に認められた証拠・会話・結果を保持します。旧保存には案内を表示し、新しい進め方を試す場合は「最初から」で全3話をやり直せます。自動で進行を消しません。旧版で複数ページを選んだままの場合は、現在の選択だけ最後の1ページへ整理し、提示済みの記録は維持します。

保存キー `trace-cases-v8` を維持し、事件ごとに進行・選択頁・閲覧頁・会話（最新160件）を保存。旧v7/v6は事件01として引き継ぎます。

やり直し確認では全3話の進行・選択・閲覧履歴・会話をまとめて初期化します。新しい初期状態を保存するため、再読み込みで以前の進行が復活することはありません。アニメ設定は維持。旧版データ自体は削除しませんが、現在の初期化済み保存が優先されます。保存できなくても画面内でプレイ可能です。
